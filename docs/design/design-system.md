# ScribeBench interface system

The generated concept in `app-concept.png` is the visual reference. The implementation keeps its open two-panel review surface, compact rail, evidence-led hierarchy, and approval footer.

- Background: true off-white `#f7f8f6`; surfaces `#ffffff`; ink `#10263b`; muted `#647384`.
- Accent: deep teal `#0b5d66`; warning rust `#b74722`; missing amber `#9a5b0b`.
- Typography: system humanist sans; compact monospace for transcript lines and metadata.
- Containers: one shell, open ruled panels, minimal 6–10px radii; no card grid.
- Motion: short opacity/translate state changes; disabled under reduced-motion preference.
- Primary workflow: line-cited transcript review → edit → approval → JSON export.

Visible product copy is limited to workflow/status language, the synthetic-only boundary, and portfolio-deployment positioning. Controls remain code-native.
