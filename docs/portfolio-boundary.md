# Portfolio deployment boundary

ScribeBench is intentionally described as a **portfolio deployment** until real authorised users, security review, clinical governance, and operational evidence exist. The repository does not claim patient outcomes, customers, hospital integration, production scale, or clinical use.

The following evidence remains pending by design:

- GPU-backed base-model evaluation on frozen held-out cases;
- LoRA training and versioned checkpoint publication;
- hosted-model comparison;
- measured GPU latency, memory, throughput, and cost;
- backup-restore rehearsal on the chosen deployment platform;
- real identity-provider integration and external security review;
- demo video with a successful and a handled-failure workflow.
